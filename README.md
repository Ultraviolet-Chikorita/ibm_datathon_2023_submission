# IBM Datathon 2023 — submission archive

This repository preserves the original packaged material for a 2023 IBM datathon submission.

> **Repository status:** archival competition material. The main artifact is [`IBM.zip`](IBM.zip), which is the retained submission/workspace bundle rather than an unpacked or reorganized source tree.

A small NLP preprocessing service used alongside this work is kept separately in `ibm_datathon2023_api`.

## Why this repository is kept

The repository records the original competition deliverable and project history. The submission archive is intentionally left in its original packaged form rather than rearranged after the fact in a way that could blur what was actually submitted.
