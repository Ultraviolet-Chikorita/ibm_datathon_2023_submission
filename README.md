# IBM Datathon 2023 — submission archive

This repository preserves the original packaged material for a 2023 IBM datathon submission.

> **Portfolio status:** archival competition material, not a primary coding sample. The main artifact is [`IBM.zip`](IBM.zip), which is the retained submission/workspace bundle rather than a reviewer-oriented source tree.

A small NLP preprocessing service used alongside this work is kept separately in `ibm_datathon2023_api`.

## Why this repository is kept

The repository records the original competition deliverable and project history. I have intentionally not unpacked/rearranged the submission archive after the fact in a way that could blur what was actually submitted.

For current applications, newer repositories provide much clearer examples of code quality, testing and research methodology.
